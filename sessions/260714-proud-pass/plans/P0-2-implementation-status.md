- 新增 "意图确认与结构化选项" 段落（62 行详细规则）

**新增内容结构**:
1. **何时需要确认**（4 类场景）
   - 任务方向不明确
   - 技术选型存在多个方案
   - 范围和优先级不清晰
   - 存在破坏性操作风险

2. **何时不需要确认**（4 类场景）
   - 单文件操作
   - 常规任务
   - 信息查询
   - 已有上下文

3. **AskUserQuestion 使用规范**
   - 问题设计原则（5 条）
   - 多问题拆分策略

4. **决策流程**（3 级判断）
   - 清晰 → 直接执行
   - 部分清晰 → 执行确定部分 + 确认不确定部分
   - 完全模糊 → 先确认再执行

5. **避免过度确认**（5 条规则）
   - 最多 3 个问题
   - 用户暗示时直接推断
   - 用户说"你来决定"时自行判断
